Running the code

  1. ·

    In your browser

    Nothing to install. The first time you press Run, the page downloads Python with NumPy, SciPy and Matplotlib (about 40 MB, kept by your browser afterwards) and runs the code inside the page.

  2. ·

    On your computer

    Faster, which helps with the longer simulations. Install the packages with pip install -r requirements.txt, then run python start_kernel.py. It opens the notes connected to your own Python.
