Preface

These notes follow CS 585, Image and Video Computing, as taught by Margrit Betke at Boston University in Spring 2024, using the lecture schedule and readings on the course’s schedule page. The first chapter covers the block on programming with images, where we follow three sets of lecture notes closely. Lecture notes 1 is a short deck on the pitfalls of programming with images, by Diane Theriault and Margrit Betke (Lecture notes 1), Lecture notes 2 is the January 30 lecture on skin colour, image differencing, template matching and image pyramids (Lecture notes 2), and Lecture notes 3 is a case study of the KidsRoom, an interactive story space built at the MIT Media Lab by Aaron Bobick and colleagues, which watched children play using little more than subtracted video frames (Lecture notes 3). The later chapters follow the rest of the schedule, image formation, tracking, edges and optical flow, deep learning and faces, stereo and multiple views, and finally generative models, reflectance, registration, transformers and ethics, built around the topics and readings listed for each lecture together with the standard papers and textbooks, mainly Horn’s Robot Vision (MIT Press, 1986) and Szeliski’s Computer Vision: Algorithms and Applications.

The slides are pretty terse (as slides should be), and a lot of the real content was said out loud or written on the board, so a student reading the PDFs a week later is basically left to reconstruct it on their own. So what I’m trying to do here is fill in that missing layer, which means that wherever a slide states a formula we derive it, and wherever a slide names an algorithm we write it out in Python and run it on a small example you can check by hand.

I’m assuming you can program, and that you remember a little bit of calculus and linear algebra, but not that you’ve ever opened an image file in code before. Everything is done with three libraries, NumPy for arrays, OpenCV for reading files (and a few other conveniences), and Matplotlib for looking at the results, so if you’re starting from scratch, this is all you need.

pip install numpy opencv-python matplotlib

A quick word on how to read these notes. Chapter 1 is about what an image actually is inside a computer, binary images and the shapes in them, finding faces and finding motion, and it has most of the traps people fall into in their first week, so if you only read one chapter carefully, make it that one. Chapter 2 asks where the numbers in an image come from, with pinhole cameras, vanishing points, lenses and a first look at stereo. Chapter 3 is about change, following objects with the alpha-beta and Kalman filters, associating detections with tracks, finding edges and active contours, and measuring optical flow. Chapter 4 brings in deep learning and faces and then the geometry of two and more views, and Chapter 5 covers the rest of the course, from GANs and diffusion models to photometric stereo, registration, transformers and the ethics of all of this.

One last remark. A lot of the methods here are old (some of them are from the 1970s), and most modern systems would just hand these jobs to a neural network, which is fine, but these are the ideas that the networks are quietly rediscovering anyway, and they’re also the tools you end up reaching for at two in the morning when you need something that works on a webcam and you don’t have any training data at all.

NoteRunning the code in these notes

Every Python cell in this book was run when the page was built, so the output is already there to read. Each cell also has a Run button. The first time you press one, the page downloads Python together with NumPy, OpenCV and Matplotlib (about 35 MB, which your browser then keeps) and runs the code right in the page. Nothing needs installing. A few cells in the later chapters also use SciPy, which the page fetches the first time one of them runs. You can edit any cell and run it again, and your output replaces the printed one.

Python in the browser is slower than on a laptop, and some packages, PyTorch among them, are not available there. For those, run the code on your own computer instead. Download start_kernel.py and requirements.txt from the course page, install the packages with pip install -r requirements.txt, and run python start_kernel.py. It opens this book connected to Python on your machine.
