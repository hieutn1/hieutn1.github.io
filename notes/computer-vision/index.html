Running the code

  1. ·

    In your browser

    Nothing to install. The first time you press Run, the page downloads Python with NumPy, OpenCV and Matplotlib (about 35 MB, kept by your browser afterwards) and runs the code inside the page.

  2. ·

    On your computer

    Faster, and it can use packages the browser cannot load, such as PyTorch. Install the packages with pip install -r requirements.txt, then run python start_kernel.py. It opens the notes connected to your own Python.
